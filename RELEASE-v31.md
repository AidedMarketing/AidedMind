# AidedMind v31 — capture setup and accessible account creation

Connection setup is now the first group in Capture & Sharing. Save & Test announces missing-token, invalid-URL and GitHub Pages server errors inline. Shortcut inbox and token copy controls appear only when the required connection settings are present. A configured server must still pass Save & Test to establish connectivity.

Owner account creation uses the shared keyboard-accessible sheet. A failed request preserves the entered name and announces the error; duplicate submissions are prevented. Account plans and backend behavior are unchanged.

Application and service-worker cache versions advance together to 31. Navigation, capture recovery, graph neighborhoods, automatic/manual links, rejection memory, notes and exports are preserved.

Validation covers worker/frontend tests, bundle dry-run and Chromium/WebKit browser QA at mobile/tablet/desktop widths, light/dark themes, reduced motion and large text. Real backend capture and physical iPhone/PWA/VoiceOver checks remain outside the fixture suite.
