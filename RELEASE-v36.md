# v36 — Source-first organization

New captures extract their topic, concepts and summary from the source alone. Library matching happens after saving. Concepts need supporting source passages; automatic connections need a direct relationship and evidence from both pieces, with generic-only overlap rejected. Shared concept names without source evidence no longer create map bridges. Unrelated pieces can remain isolated.

More → Appearance → Review organization prepares saved topic/concept/tag proposals without changing accepted knowledge or summaries. Preview, select and apply changes; manually chosen topics stay protected. Progress, Pause/Resume, failed-item retry, source checks and Undo survive reopening. Load more keeps large reviews manageable. Applying or undoing queues library connection checks. Preparing proposals and checking connections use model tokens; both costs are explained before starting. A new review replaces the previous Undo history.

Short article captures are flagged for inspection. Import missing full text, or inspect a genuinely complete short article and confirm Text is complete. Confirmation expires when captured text changes. Nothing starts a paid organization review solely because the app updated.

Verification uses synthetic fixtures based on failure classes found in a real library audit; no private backup content is published. Model classification and semantic relevance remain judgments, so review the proposed changes before applying them.
